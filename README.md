# SkateGTA

Перенос [Skate 3 Rust Engine](https://github.com/SK8-ENGINE/skate-3-rust-engine)
в GTA V (Legacy) как плагин ScriptHookV. Физика доски — это восстановленное
ядро Skate 3 (`skate-core`) без изменений; все физические параметры читаются
из **ваших** файлов Skate 3, сконвертированных установщиком skate3rust.
Встроенных/подставных значений нет: без ваших данных мод не запустится.

## Статус

| Этап | Что | Состояние |
|---|---|---|
| 1 | Каркас: `.asi` на Rust, ядро Skate 3, доска на коллизии GTA | **готово** |
| 2 | Полная игра Skate 3: езда, толчок, тело скейтера, flick-it, олли, камера | **готово** |
| 3 | Очки трюков и оригинальный HUD Skate 3 (`Hud`) | **готово** |
| 4 | Грайнды: поиск рельсов в мире GTA | |
| 5 | Анимация скейтера на педе GTA (`PedPose`) | **первая версия** |

`Gameplay = full` (по умолчанию) запускает всю игровую логику Skate 3 Rust Engine
(`skate-gameplay`, около 60 тыс. строк, перенесено без Bevy): графы действий и
движения, физические состояния (земля, воздух, грайнд, падение, без доски),
общее решение доски и тела скейтера, распознавание жестов стика и камеру Skate 3.
`Gameplay = board` оставляет только физику доски с тестовым управлением.

## Установка

1. **Сконвертируйте свои файлы Skate 3 (один раз).** Скачайте
   [skate3rust](https://github.com/SK8-ENGINE/skate-3-rust-engine/releases/tag/experimental),
   запустите `skate3rust.exe` и выберите свой `default.xex` (рядом с ним должна
   лежать папка `data`). После конвертации появится
   `skate3rust\data\installations\<id>\assets`.
2. **Положите мод в папку GTA V** (там, где `ScriptHookV.dll` и `dinput8.dll`):
   `SkateGTA.asi` и `SkateGTA.ini`.
3. **Откройте `SkateGTA.ini`** и укажите `Skate3RustDir` — папку, где лежит
   `skate3rust.exe`. Либо `AssetRoot` — сразу папку `assets`.
4. **Модель доски (по желанию).** В GTA V нет модели скейта. По умолчанию мод
   двигает объект `p_defilied_ragdoll_01_s`; замените его моделью скейта
   (как в моде SkateV) или укажите другой объект в `BoardModel`.

Полной игре нужны из `assets\private\stock\`: `skater-collections.json`,
`physics-skeletons.json`, `data\anim\OnBoard.abin`, `data\anim\OffBoard.abin`,
`data\state\ActionGraph_OnBoard.stategraph`, `data\state\MotionGraph_OnBoard.stategraph`,
`data\script\camera\Default_cameragraph.stategraph`, `data\camera\1.shk`,
`data\camera\2.shk` и 7 файлов `data\joystick\*.pat`. Если чего-то нет, мод
перечислит недостающие файлы.

HUD трюков берётся из `assets\private\hud\` (`runtime\trickdisplay.json`,
текстуры `assets\data\fe\...\*.Texture.rgba` и шрифты futura). Это оригинальный
APT-ролик Skate 3 с его ActionScript: название трюка, очки, CLEAN/SKETCHY,
множитель. Мод вырезает нужные куски текстур в PNG (`SkateGTA\hud\` рядом с
`.asi`) и рисует их через ScriptHookV. Если папки `hud` нет, игра работает без HUD
(в логе будет причина).

## Управление (геймпад, раскладка Skate 3)

| Действие | Кнопка |
|---|---|
| Включить / выключить | **F5** (`ToggleKey`) или **Back** |
| Толчок | **A** (правая нога) / **X** (левая) |
| Руление, наклон | левый стик |
| Олли и трюки (flick-it) | правый стик: вниз и резко вверх — олли |
| Мануал | правый стик слегка вверх/вниз |
| Тормоз, спрыгнуть в воздухе | **B** |
| Захваты в воздухе, присед | **LT** / **RT** |
| Схватиться за уступ, хэндплант | **RB** |
| Сойти с доски / встать обратно | **Y** |

Камера — камера Skate 3 (`SkateCamera = 0` вернёт камеру GTA). С `PedPose = 1`
ваш персонаж GTA принимает позу скейтера Skate 3 каждый кадр (ретаргетинг по
направлениям костей, `pose.rs`; скелет педа находится в памяти по тому же пути,
что у ScriptHookVDotNet). GTA пересчитывает кости педа уже после скриптов,
поэтому по умолчанию (`PedPoseMode = guard`, экспериментально) страница с
матрицами костей охраняется guard-страницей, и поза Skate 3 записывается сразу
после того, как GTA допишет последнюю кость; первые кадры мод также пишет в лог,
какой код GTA обращается к костям. `PedPoseMode = script` пишет позу только из
скрипта. `DebugBody = 1` дополнительно рисует скелет Skate 3
линиями. Доска рисуется линиями, пока `BoardModel = none`. Зелёная сетка —
земля GTA, которую получает физика (`DebugDraw = 0` выключит).

## Как это устроено

- `skate-core` и `skate-data` подключены из оригинального репозитория по
  зафиксированному коммиту; код ядра не менялся.
- `settings.rs` и `colliders.rs` перенесены из `skate-game` (без Bevy).
- GTA отвечает только на лучи, а ядру нужны треугольники. Поэтому вокруг доски
  строится сетка лучей вниз (`terrain.rs`), ровные блоки сворачиваются в два
  треугольника, а мелкая сетка остаётся у бордюров и рамп.
- Координаты: GTA (Z вверх) ↔ Skate 3 (Y вверх), с плавающим началом в точке
  появления (`coords.rs`).
- Игровая логика оригинала (`skate-game`) перенесена в `skate-gameplay`;
  Bevy заменён крошечной прослойкой `bevy-shim` (логи, glam, `Transform`).
- Тик идёт с частотой оригинала (60 Гц), полный тик ~2 мс. Игра работает в
  отдельном потоке с большим стеком; лучи GTA — в файбере ScriptHookV.
- Камера и прогнозы траектории Skate 3 видят землю GTA в радиусе 16 м через
  грубую сетку высот (`far.rs`), которая дозаполняется по мере движения.
- ScriptHookV подгружается в рантайме, импорт-библиотека не нужна.
- HUD: ролик `trickdisplay` крутится той же виртуальной машиной ActionScript,
  что и в оригинале (`hud_runtime`, `apt_vm`), после каждого тика физики;
  каждый прямоугольник ролика (фигура или буква) становится экземпляром
  текстуры `drawTexture`, холст 1280x720 сохраняет пропорции 16:9.

Ограничения: вертикальные стены и высокие бордюры видны физике как крутые
скаты (лучи только сверху вниз); рельсов для грайндов пока нет; пед GTA не
анимирован — он стоит на месте бёдер скейтера Skate 3.

## Сборка

Нужен Rust 1.85+.

```sh
# из Linux/WSL (кросс-компиляция, нужен mingw-w64)
rustup target add x86_64-pc-windows-gnu
cargo build --release --target x86_64-pc-windows-gnu
# target/x86_64-pc-windows-gnu/release/skate_gta.dll -> SkateGTA.asi

# на Windows
cargo build --release
# target/release/skate_gta.dll -> SkateGTA.asi

cargo test   # тесты физики на синтетической земле

# проверки на ваших сконвертированных данных Skate 3
SKATE_GTA_ASSETS=<skate3rust>/data/installations/<id>/assets cargo test --workspace
```
