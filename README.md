# SkateGTA

[English](README.en.md) · **Русский**

Физика и игровая логика Skate 3 в GTA V Legacy через ScriptHookV. Мод использует [Skate 3 Rust Engine](https://github.com/SK8-ENGINE/skate-3-rust-engine) и ваши собственные сконвертированные файлы Skate 3. Игровые данные и ассеты в репозиторий не входят.

## Обновление v10

- Поиск гриндов ориентируется по движению игрока, включая скольжение боком и езду назад. Когда игрок стоит, используется его направление при ходьбе либо направление доски при катании.
- Уступы сначала ищутся в коридоре до 10 метров впереди. Лучи поиска поручней направлены вперёд и по обе стороны от движения; найденный поручень трассируется сначала вперёд.
- Новые участки добавляются во время гринда и полёта с сохранением ранее опубликованных сегментов, их владельцев и GUID.
- Прямые поручни больше не создают сотни лишних секций коллизии. Изгибы сохраняются с погрешностью до 5 мм.
- Поддержаны наклонные поручни, узкие верхушки ограждений и изогнутые бортики. Сохранены исправления заезда в чашу и на непрерывный уклон; бордюр требует прыжка.

Поиск распределён на несколько кадров с ограниченным бюджетом лучей. Дальность 10 метров не означает мгновенного обнаружения всех объектов и зависит от доступной коллизии GTA. Поручень без коллизии в самой GTA не определяется этими лучами.

## Возможности

Полный режим (`Gameplay = full`) включает езду, толчки, flick-it, олли, мануалы, захваты, гринды, ходьбу с доской, камеру, анимацию персонажа и оригинальный HUD трюков Skate 3. Физические параметры читаются из ваших данных. Режим `Gameplay = board` оставляет отдельную симуляцию доски с тестовым управлением.

В полной игре контакты проверяются по настоящим shape-test лучам GTA. Подтверждённые поручни также получают узкую контактную сетку. Коробки целых объектов и прежние красные кубы не добавляются. Физику доски и скейтера решает движок Skate 3.

## Установка

1. Установите ScriptHookV для GTA V **Legacy**.
2. Сконвертируйте собственные файлы Skate 3 установщиком [skate3rust](https://github.com/SK8-ENGINE/skate-3-rust-engine/releases/tag/experimental): выберите `default.xex`, рядом с которым находится папка `data`. Результат появится в `data/installations/<id>/assets`.
3. Полностью закройте GTA V. Положите `SkateGTA.asi` и `SkateGTA.ini` рядом с `GTA5.exe`, `ScriptHookV.dll` и `dinput8.dll`.
4. В INI укажите `Skate3RustDir` — папку со `skate3rust.exe`, либо `AssetRoot` — непосредственно папку `assets`.
5. Запустите игру и нажмите **F5** или **Back** на геймпаде.

При обновлении заменяйте ASI с закрытой игрой и сохраняйте свой INI. Если не хватает данных, причина записывается в `SkateGTA.log`.

Полной игре нужны коллекции, физический скелет, анимации OnBoard/OffBoard, графы действий и движения, граф камеры и шаблоны джойстика в `assets/private/stock`. Список недостающих файлов выводится в журнал.

Модель доски (`BoardModel = skate3`) читается из `assets/private/skater.glb`. Можно выбрать объект GTA либо `none` для отрисовки линиями. Оригинальный HUD берётся из `assets/private/hud`; без него игра продолжает работать без HUD. Звуки (`Audio = 1`, `AudioVolume`) используют `assets/private/audio`, AEMS, банки и WAV. Недостающие звуковые банки остаются беззвучными и перечисляются в журнале.

Для удаления закройте GTA V и уберите `SkateGTA.asi`.

## Управление

Раскладка геймпада Skate 3:

| Действие | Кнопка |
|---|---|
| Включить / выключить | F5 или Back |
| Толчок правой / левой ногой | A / X |
| Руление и наклон | Левый стик |
| Олли и flick-it | Правый стик: вниз, затем резко вверх |
| Мануал | Правый стик слегка вверх / вниз |
| Тормоз / спрыгнуть в воздухе | B |
| Захваты и присед | LT / RT |
| Хэндплант / схватиться за уступ | RB |
| Сойти с доски / вернуться | Y |

## Настройки и диагностика

- `SkateCamera = 0` возвращает камеру GTA.
- `PedPose = 1` переносит позу Skate 3 на персонажа GTA. Режим `PedPoseMode = hook` перехватывает копирование матриц костей; `script` записывает позу из скрипта, а `guard` служит для диагностики и работает медленнее.
- `DebugDraw = 1` показывает жёлтые линии гринда и зелёную сетку земли. `DebugBody = 1` показывает скелет. Для обычной игры отладочную отрисовку можно отключить.
- `CollideWalls` относится к прежним коробкам и в полной игре не применяется. `CollideEntities` управляет реакцией прохожих на удар.
- Журнал содержит `Performance v10` с временем поиска и физики, а также сведения о найденных линиях и запуске мода.

## Проверки и ограничения

Для v10 прошли 75 выбранных проверок: 62 библиотечных, 4 бордюра, 2 гринда, 4 поручня, 2 подъёма/перехода чаши и проверка потокового провайдера. Проверены поиск у отметки 9,5 м, направление движения при повёрнутой доске, наклонные поручни и сохранение контактов при добавлении продолжения. В тестовой сцене нативный гринд держится 181 последовательный кадр.

Это проверки с игровым кодом и синтетическими пробами поверхности, включая ваши сконвертированные данные. Они не подтверждают все места в GTA или конкретный FPS. Разреженные пробы могут пропускать геометрию. Падение при ударе о стену пока не всегда срабатывает: скейтер может остановиться вместо падения. Анимация персонажа и поиск гриндов продолжают дорабатываться.

## Сборка из исходников

Для проверенной сборки использованы Rust 1.99.0, Windows x64 и MSVC Build Tools. Зависимости Skate 3 Engine закреплены на коммите `b3c967932a91d0db74275d14064bb6bdef8608af`. Доступ к GitHub нужен для их загрузки.

```powershell
cargo build --release -p skate-gta -j 1
Copy-Item target/release/skate_gta.dll SkateGTA.asi
```

Для снижения расхода памяти при сборке игрового модуля:

```powershell
cargo build --release -p skate-gta -j 1 --config 'profile.release.package.skate-gameplay.debug=0'
```

Выбранные проверки с вашими файлами:

```powershell
$env:SKATE_GTA_ASSETS = 'D:/skate3rust/data/installations/<id>/assets'
cargo test -p skate-gta --lib --test curb --test grind --test handrail --test transition -j 1 --config 'profile.dev.package.skate-gameplay.debug=0'
cargo test -p skate-gameplay --test streaming_provider -j 1 --config 'profile.dev.package.skate-gameplay.debug=0'
```

Без `SKATE_GTA_ASSETS` проверки, требующие частных данных, пропускаются. Полный набор библиотечных тестов `skate-gameplay` требует отсутствующих в этой копии файлов upstream-тестов; приведённые команды проверены отдельно.
